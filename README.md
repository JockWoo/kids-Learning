# 🌟 幼兒小學堂 (Kids Learning Web Apps)

> 專為 3~6 歲學齡前幼兒設計的互動學習遊戲平台（純前端 Web 應用，免安裝，支援 iPad / 平板 / 手機 / 桌面端觸控遊玩）。

---

## 🎮 三大學習模組 (Modules)

### 1. 🧮 小小數學家 (Math App & Mini Games)
- **路徑**：`/` 或 `/index.html`
- **核心功能**：
  - 🍎 **數一數**：圖像認知與計數 (0–20)。
  - ➕ **加法冒險**：視覺化物品加法運算。
  - ➖ **減法冒險**：吃掉/拿走的視覺化減法運算。
  - 🚀 **每日大冒險**：10 題綜合混合挑戰。
  - 🎮 **3 大互動小遊戲 (Mini Game Module)**：
    - 🍎 **接水果 (Catch Fruit)**：滑動籃子接住正確數字與算式。
    - 🐲 **餵怪獸 (Feed Monster)**：手指拖曳水果餵食可愛怪獸。
    - 🔐 **寶箱密碼 (Treasure Box)**：算術解密開啟海盜寶箱與金幣噴泉。

### 2. 🔤 ABC 英文探險 (English App)
- **路徑**：`/english/`
- **核心功能**：
  - 認字母 A~Z、看圖猜單字、字母排序接龍。
  - 幼兒專屬 0.65x 慢速美式發音與生字圖卡。

### 3. 🔤 注音 ㄅㄆㄇㄈ 小學堂 (Zhuyin App & 筆順手順)
- **路徑**：`/zhuyin/`
- **核心功能**：
  - 認注音符號 (ㄅ~ㄦ 全 37 個符號)。
  - 看圖猜注音、注音大冒險。
  - ✍️ **注音手順 (筆畫教學)**：
    - 教育部標準標楷體字帖引導。
    - 醒目紅色數字標記 **① ② ③** 搭配方向箭頭（↙ ⤵ ↘）。
    - 標準米字格手指自由手寫描紅、多筆劃留痕與一鍵清除重寫。

---

## ⚙️ 家長設定 (Parent Mode)
- **範圍調整**：入門 (4 符號 / 0–5)、基礎 (11 符號 / 0–10)、進階 (全 37 符號 / 0–20)。
- **發音速度**：慢速 (0.5x)、幼兒 (0.65x)、標準 (0.8x)。
- **每局題數**：5 題、10 題、20 題。
- **星星獎勵**：本地 localStorage 永久記錄 cumulative stars。

---

## 🚀 本地啟動 (Local Run)

```bash
# 數學小學堂 & 小遊戲
python3 -m http.server 8080

# 英文探險
cd english && python3 -m http.server 8085

# 注音小學堂
cd zhuyin && python3 -m http.server 8095
```
